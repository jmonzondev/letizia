# Proyecto Letizia

Base documental del proyecto: landing, automatización de noticias, copias de seguridad, contraseñas y cuentas.

## Documentos

| Archivo | Qué es |
|---|---|
| `docs/presupuesto/01-propuesta.md` | Plantilla de propuesta y presupuesto por módulos, en tres niveles |
| `docs/presupuesto/02-condiciones.md` | Hoja de condiciones de una página que acompaña a la propuesta |
| `docs/presupuesto/03-cuestionario-fase0.md` | Lo que hay que pedir a la clienta para arrancar (Fase 0) |
| `docs/presupuesto/04-tarifas.md` | Precios por módulo y por nivel a 15, 20, 25, 30, 35 y 40 €/h |
| `docs/presupuesto/calcular_tarifas.py` | Script que regenera `04-tarifas.md` si cambian horas, tarifas o porcentajes |

Los importes marcados con `[ ]` son huecos a rellenar. Las horas son orientativas y se revisan tras la Fase 0.
